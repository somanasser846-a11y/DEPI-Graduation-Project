<h2>Brief</h2>

<p dir="rtl">
منصة إلكترونية متكاملة لمنتجات العناية والتجميل تهدف إلى تقديم تجربة تسوق سلسة واحترافية للعملاء، وتوفير حلول ذكية لإدارة المبيعات والمنتجات بأسلوب عصري ومتطور.
</p>

<h2>Project Idea</h2>

<p dir="rtl">
المشروع عبارة عن متجر إلكتروني متكامل ومتطور يتيح للمستخدمين تصفح المنتجات والبحث السريع، وإدارة السلة والدفع الإلكتروني، بالإضافة إلى إنشاء حساب شخصي وتتبع الطلبات.
</p>

<p dir="rtl">
كما يتضمن لوحة تحكم خاصة بالإدارة
<strong>(Admin Dashboard)</strong>
لإدارة المنتجات والطلبات والعملاء، ونظام عروض وباقات مخصصة للروتين اليومي، مثل العناية بالبشرة والشعر.
</p>

<p dir="rtl">
كما يحتوي المشروع على نظام إدارة علاقات العملاء
<strong>(CRM)</strong>
لفهم سلوك واحتياجات العملاء بشكل أفضل، وتوفير تجربة تسوق مخصصة ومميزة.
</p>
